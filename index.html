Smali 組合語言速查與教學

Smali 是 Android Dalvik/ART 虛擬機的可讀組合語言。以下整理常見語法指令與範例。

字串與數值

const-string v0, "Hello"

將字串常數加載進暫存器 `v0` 中。

Java Equivalent
String text = "Hello";
方法調用

invoke-virtual {v0, v1}, LMethod;

調用物件的虛擬方法（Virtual Method），傳入暫存器參數。

Java Equivalent
object.doSomething(arg1);
欄位存取

iget-object v0, p0, LClass;->field

從目前物件（`p0`）中讀取物件欄位（Field）數值至暫存器 `v0`。

Java Equivalent
this.field = value;
邏輯跳轉

if-eqz v0, :cond_0

若暫存器 `v0` 等於 0 (null / false)，跳轉至標籤 `:cond_0`。

Java Equivalent
if (flag == false) { ... }
傳回值

return-void

代表無傳回值（void）之方法結束指令。

Java Equivalent
return;
取得回傳值

move-result-object v0

取得上一次方法調用所傳回之物件引用，存入 `v0`。

Java Equivalent
Object res = method();

Apktool 運作架構與核心原理

理解 APK 解包、Dex -> Smali 轉換、資源重建與重構封裝的全脈絡運作圖解。

01

APK 二進位解包

APK 本質為 ZIP 封包。Apktool 將其解開並分離 `classes.dex`、`resources.arsc`、`AndroidManifest.xml` 與 `res/`。

02

Baksmali & 資源解析

利用 Baksmali 將位元組碼拆解為人類可讀之 Smali，同時將二進位 XML 轉換為標準可編輯 XML 文字。

03

開發者修訂與在地化

使用者進行繁體中文化、程式碼注入、佈局微調或套用修補檔。

04

Smali 彙編與 AAPT2 重建

將修改後的 Smali 組裝回 `classes.dex`，並由 AAPT2 重新編譯資源並打包為全新二進位 APK。

涵蓋安裝配置、OEM 框架檔匯入、APK 重建金鑰簽署與常出現疑難排解。

各作業系統安裝說明

1. Windows 環境

  1. 下載最新版 apktool_x.x.x.jar 並重新命名為 apktool.jar。
  2. 下載 Windows 批次檔腳本 apktool.bat。
  3. 將上述兩檔案移動至系統路徑目錄（例如 C:\Windows 或放置於自訂資料夾並加入環境變數 PATH）。
  4. 開啟 PowerShell 或 CMD 視窗輸入 apktool 即可啟動。

2. macOS / Linux 環境

# 賦予執行權限並移動至 usr local bin
chmod +x apktool.sh apktool.jar
sudo mv apktool.sh /usr/local/bin/apktool
sudo mv apktool.jar /usr/local/bin/apktool.jar
apktool --version

系統層框架檔 (Framework) 之安裝與使用

部分由手機原廠（如 Samsung, Xiaomi, LG 等）客製之系統 APK，在解碼時會引用原廠非標準的資源 ID。此時需先從手機的 /system/framework 目錄提取 framework-res.apk 並匯入：

# 匯入原廠框架檔
apktool if framework-res.apk

# 解碼時引用已匯入之框架
apktool d system_app.apk

APK 重建後之簽署 (Resigning APK)

經由 apktool b 重建產出之 APK 檔未具備數位簽署，直接安裝於 Android 裝置將會回報 INSTALL_PARSE_FAILED_NO_CERTIFICATES 錯誤。請使用 Uber-APK-Signer 或 standard apksigner 進行簽署：

# 產生測試金鑰
keytool -genkey -v -keystore my-key.keystore -alias my-alias -keyalg RSA -keysize 2048 -validity 10000

# 簽署新建構之 APK
apksigner sign --ks my-key.keystore new_target.apk

常見問題與除錯經驗

Q: 為何反編譯時出現 CantFindFrameworkResException 錯誤？

答：這代表該 APK 引用了系統層限定資源。請依據「框架檔管理」步驟匯入對應手機原廠 ROM 的 framework-res.apk。

Q: 回編譯時出現 aapt: error: resource ... not found？

答：請嘗試加上 --use-aapt2 旗標使用 AAPT2 重建，或檢查 `res/values/public.xml` 中的資源 ID 聲明是否正確。
